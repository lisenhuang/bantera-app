# Bantera 2.29.4 (408)

Prepared 20 October 2026. Builds on the uncommitted 2.29.3 (407) changes documented alongside this release. No commit, push, backend change or App Store submission.

## Practice controls

- Daily-goal progress (or Set goal) is on the left of the fixed toolbar; the text-only Longer dialogues overflow menu is on the right. Practice remains centred and the toolbar stays 56 points tall. Both controls retain 48-point touch targets.
- The instruction above Cue 1 is replaced by a localised Level button displaying the exercise level. It opens a scrollable modal sheet with A1–C2, the current earned level, selected state and How levels work? help.
- Higher levels remain grey but tappable for the existing explanation. Lower-level practice still requires confirmation and does not replace the earned level. Dismissing the sheet leaves the exercise, answer and translation state intact. Recording/processing still disables level changes.
- The reward animation keeps the same goal anchor, which now follows the left-hand goal control.

Native tests completed on the actual iOS 17.0 runtime: 36 total, 34 passed, two physical-device acoustic tests skipped, zero failures.
